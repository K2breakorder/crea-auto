# 広告ルールチェック

`knowledge/regulations.md` を読み、下の7項目で採点する（各○/△/×）。

1. 効果効能：治る・改善を約束していないか。症状名＋「効く」と読めないか
2. 技能・経歴：「高い技術」「○○流」「第一人者に師事」など技能の強調がないか
3. 比較・誇大：No.1・唯一・口コミ1位・絶対・必ずがないか
4. 医療的表記：診療・診察・初診・往診・保険取扱い・交通事故取扱い・認定表示がないか
5. 料金：安さを過度に強調していないか。特典は期間と条件があるか
6. 写真・体験談：加工したビフォーアフターがないか。お客様の声は同意があるか
7. 媒体の規約：Googleの不承認理由（電話番号の本文記載など）、HPB掲載基準、Metaのガイドライン

## 出し方
- ×がある時：該当箇所 → 理由 → 言い換え案、を表で出し、直した全文を出す
- △だけの時：気になる箇所と、より安全な言い換えを1つずつ
- 全部○の時：「チェック済み（日付）」と1行

直した表現のうち、次回も使える言い換えは `knowledge/learnings.md` に追記する。
