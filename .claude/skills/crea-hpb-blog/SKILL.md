# ホットペッパービューティー ブログ

## 先にやること
1. `/crea-latest-check`（HPB・SALON BOARD）
2. `knowledge/learnings.md` の HPB の学びを読む
3. メニュー名を `config.yaml` から取る。クーポン名はHPB上の表記と完全一致させる（分からなければ聞く）
4. HPBは「鍼」「灸」「症状」「施術所」なども登録不可ワード（`crea/compliance.py` の HPB_NG）。言い換えて書く

## 型
- カテゴリ：おすすめメニュー／サロンのNEWS／その他 から選ぶ
- タイトル（25字前後）：お悩みの場面＋メニュー名。例「立ち仕事の脚の重さに。○○コースのご案内」
- 一覧で見える冒頭2行に、誰向けか・何ができるかを入れる（「続きを見る」の前で判断される）
- 本文（400〜800字目安）：
  1. よくあるご相談の場面（症状名は「お悩み」として触れるだけ、「効く」とは書かない）
  2. 施術の流れと所要時間
  3. 担当者が国家資格を持つ旨（技能や経歴の強調はしない）
  4. 該当クーポン名（HPBの表記どおり）と予約の案内
- 写真：院内・施術の様子・メニュー画像。加工した施術前後写真は使わない
- 絵文字は控えめ（1段落に1つまで）

## 保存とチェック
`posts/hpb/YYYY-MM-DD_<題名>.md` に保存（タイトル・カテゴリ・本文・写真指示・紐づけクーポン）。
`/crea-ad-review` を通してから、SALON BOARD に手で貼る形で出す（HPBは公開APIが無いため自動投稿はしない）。

## 効果の確かめ方
SALON BOARD の分析で、ブログ公開週のページビュー・予約数を前週と比べ、`knowledge/learnings.md` に1行残す。
