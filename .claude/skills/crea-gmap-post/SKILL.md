# Googleマップ投稿（Googleビジネスプロフィール）

## 先にやること
1. `/crea-latest-check`（Googleビジネスプロフィール）
2. `knowledge/learnings.md` の Googleマップ の学びを読む
3. `config.yaml` の clinic・strategy からメニュー・アクセス・営業時間・検索語を取る（無ければ作らずに聞く）
4. 今週の `data/queue/` に Googleマップ投稿が既にあれば、テーマが重ならないようにする（自動で週3本：火・木・土）

## 型（最新情報）
- 1行目（約60字以内）：検索される言葉を自然に入れる。例「三島駅近くで、デスクワークの合間に体を整えたい方へ」
- 本文（200〜400字目安、上限1,500字）：
  1. 誰のどんな場面か（生活の場面から入る）
  2. Creaでできること（施術の内容・流れ・時間。効果は約束しない）
  3. 院の事実（国家資格を持つ施術者／三島駅からの道順／予約優先／駐車場）
- ボタン：「予約」または「詳細」。リンクは計測用に `?utm_source=gbp&utm_medium=post&utm_campaign=YYYYMM` を付ける
- 写真：院内・施術の様子（お客様の顔なし）。加工したビフォーアフターは使わない
- 電話番号は本文に書かない（Googleが不承認にしやすい。ボタンかプロフィールの電話欄を使う）

## 種類の使い分け
- 最新情報：季節の体の悩み・院の様子・新メニュー
- 特典：初回の案内など。安さを強調しすぎない（「半額」「激安」は使わない）。期間と条件を必ず書く
- イベント：期間限定の受付・休診のお知らせ

## 保存とチェック
`posts/gmap/YYYY-MM-DD_<題名>.md` に、本文・ボタン種類・リンク・写真の指示を書いて保存。フックが `crea/compliance.py` で広告チェックをする。
最後に `/crea-ad-review` を通し、1案目と改善した2案目を並べて出す。

## 効果の確かめ方
投稿した週としない週で、パフォーマンス画面（表示・通話・ルート・ウェブサイトクリック）を比べ、`knowledge/learnings.md` に1行残す。
