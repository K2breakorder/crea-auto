# X運用AIチームの構築（Crea版）

1. `prompts/x_team_setup.xml` を全文読み、その指示どおりに進める（あなたは統括役）。
2. 必ず `<start>` から始める：ジャンル・読者・口調・参考にするアカウントの **4つを質問して止まる**。答えが出るまで何も作らない。
3. 答えが出たら、次の順で1段ずつ作り、各段の終わりで確認を取る：
   1. ルールブック `x-team/rulebook.md`（一番怖い事故を一番上）
   2. チーム構成図と各係の定義 `x-team/agents/scout.md` `smith.md` `linker.md`（読むもの・書くもの・次に渡すもの）
   3. 手順書 `x-team/runbook.md` と定時の作業の一覧 `x-team/schedule.md`
   4. 検査ツール `x-team/qa_check.py`（承認されていない実績の数字・見本との10文字以上の一致・同じ枠の重複を拒否し、理由を表示）
   5. 最後に投稿の自動化（検査ツールが動いてから）
   6. 「ここから始める」

## Crea のリポジトリで守ること（プロンプトより優先）
- `CLAUDE.md` の広告ルール（あはき・柔整広告ガイドライン、景表法、薬機法）をX投稿にもそのまま当てる。検査ツールは `crea/compliance.py` の NG語チェックも呼ぶ。
- 院の情報は `config.yaml` だけから取る。「業界歴35年」など経歴・技能の強調は書かない。電話番号は載せない。
- お客様の声・ビフォーアフター・効果の約束は書かない。
- X の操作は公式 X API のみ。ブラウザ操作・非公式ツールは使わない。キーは GitHub Secrets（`X_API_KEY` など）にだけ置く。
- X API は従量課金（投稿の読み取り・作成ごとに料金）。監視アカウントの数と取得件数は、月の見込み額を出して確認を取ってから決める。
- 既存の自動化（`.github/workflows/`、`data/queue/`）に組み込む変更、`git push` は毎回確認を取る。
