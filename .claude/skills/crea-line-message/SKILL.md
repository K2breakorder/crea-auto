# LINE 配信文

## 決まり
- 配信は `config.yaml` の line_broadcast（第1週の木曜）に合わせる。無料プランは月200通。自動配信は残り通数を確認して足りなければ見送る
- 1通は「吹き出し1つ＋画像1枚」まで。最初の2行で用件が分かるように
- 既存のお客様向けでも、不特定多数に送る配信は広告として扱い、広告ルールを守る
- 予約リンク・LINE上の予約導線は1つに絞る

## 型
1. あいさつ（季節の一言）
2. お知らせ本題（空き状況・新メニュー・休みのお知らせ など）
3. 予約方法（1つ）

## 感情設計（LINEの担当は ④⑤）
- LINEは関係ができた人向け。5段階の感情設計（`crea/generate.py` の strategy_block）のうち、④未来の疑似体験（具体的な朝や休日の場面）と ⑤アイデンティティの転換（「我慢する私」を卒業してもいい、という院の考え方）を担当する
- 語り口は院長からの手紙。短い文で改行を多めにし、「迷ったらこのLINEに一言ください」で返信しやすくする
- 登録直後の7通ステップ配信の見本：Claude Docs「Crea LINEステップ配信 7通（5段階感情設計）」（リポジトリは公開なのでURLは書かない）

## 保存
`posts/line/YYYY-MM-DD_<題名>.md`。フックが `crea/compliance.py` で広告チェック、最後に `/crea-ad-review`。
