# LINE 配信文

## 決まり
- 配信は `config.yaml` の line_broadcast（第1週の木曜）に合わせる。無料プランは月200通。自動配信は残り通数を確認して足りなければ見送る
- 1通は「吹き出し1つ＋画像1枚」まで。最初の2行で用件が分かるように
- 既存のお客様向けでも、不特定多数に送る配信は広告として扱い、広告ルールを守る
- 予約リンク・LINE上の予約導線は1つに絞る

## 型
1. あいさつ（季節の一言）
2. お知らせ本題（空き状況・新メニュー・休みのお知らせ など）
3. 予約方法（1つ）

## 保存
`posts/line/YYYY-MM-DD_<題名>.md`。フックが `crea/compliance.py` で広告チェック、最後に `/crea-ad-review`。
