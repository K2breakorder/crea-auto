# 広告ルールまとめ（Crea用）

最終確認：2026-11-10（/crea-latest-check で更新する）

## 根拠
- あん摩マツサージ指圧師、はり師、きゆう師等に関する法律 第7条：法律で認められた事項以外は、誰がどんな方法でも広告できない
- 厚生労働省「あはき・柔整広告ガイドライン」（令和7年2月18日 医政発0218第1号）
  - 概要資料：https://www.mhlw.go.jp/content/10800000/001412682.pdf
  - 通知本文：https://www.mhlw.go.jp/content/10800000/001412949.pdf
- 景品表示法（優良誤認・有利誤認、2023年10月からステルスマーケティング規制）
- 薬機法（美容メニュー・物販の効能表現）

## 広告になる条件（3つすべて満たすと広告）
誘引性（来院を促す）／特定性（どの院か分かる）／認知性（不特定多数が見られる）。
SNS投稿・Googleマップ・HPB・LINE一斉配信は基本「広告」として扱う。

## 書いてよいこと（例）
- 国家資格を持っている旨（「国家資格保有」）
- 施術所名、住所、最寄駅からの道順、案内図、電話番号、受付時間
- 施術日・時間、予約優先の旨、休日・夜間の施術
- 出張できる範囲や時間（「往療」は可、「往診」「訪問診療」は不可）
- 駐車場の有無・料金
- 届出済みの旨（「厚生労働省認定」「指定」は不可）

## 書かないこと
| 種類 | 例 |
|---|---|
| 技能・施術方法・経歴 | 高い技術、○○流、第一人者に師事 |
| 虚偽・誇大 | 実態と違う内容、絶対治る |
| 比較優良（事実でも不可） | 県内で唯一、口コミサイトで1位 |
| 効果効能 | 腰痛・肩こり等の症状に効く、と受け取られる表現 |
| 料金の過度な強調 | 激安、最安 |
| 医療的表記 | 診療、診察、往診、初診、各種保険取扱い、交通事故取扱い |
| 写真 | 加工・修正した施術前後写真 |
| あおり | 早急な受療を過度にあおる表現 |

## ウェブサイトに載せるべきこと
問合せ先／自費施術の内容と通常の料金／主なリスクや副作用／回数券などの契約内容。
