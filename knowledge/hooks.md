# 冒頭フックの型（1行目の作り方）

投稿の1行目（Googleマップ・ブログは冒頭2行）を、下の型のどれかで作ります。
毎週の自動生成はこの表を読み、使った型の番号を投稿ごとに `hook` として記録します。
毎晩の集計（`crea/report.py`）が型ごとの反応を出すので、伸びた型を増やし、伸びない型は例文を直します。

書き方の決まり：効果を約束しない／不安をあおらない／最上級・比較を使わない（`crea/compliance.py` が正）。

| 番号 | 型 | ねらい | 例（そのまま使わず、その週の話題に置き換える） |
|---|---|---|---|
| H1 | 問いかけ | 自分のことだと気づいてもらう | 雨の日、頭まで重くなる感じはありませんか？ |
| H2 | あるある場面 | 朝・仕事中・寝る前など、場面を1つ描く | 朝、うがいで上を向くと首がつっぱる。 |
| H3 | 意外な仕組み | 「へえ」と思うからだの仕組みを1つ | 気圧の変化を感じ取っているのは、耳の奥でした。 |
| H4 | 数字 | 短さ・少なさで試しやすくする | 寝る前30秒、耳まわりをゆるめる3つの動き。 |
| H5 | 季節・天気 | 今週の三島の天気や行事から入る | 今週の三島は朝晩の気温差が大きくなりそうです。 |
| H6 | 地域・通いやすさ | 三島駅・近隣の地名で検索に合わせる | 三島駅南口から歩いて3分。仕事帰りに寄れる場所です。 |
| H7 | 思い込みをほどく | よくある対処の見落としをやさしく示す | 肩がつらい日に肩だけをもむ、で終わっていませんか。 |
| H8 | 対象をしぼる | 年代・生活で呼びかける | デスクワークが続く50代の方へ。 |
| H9 | 手順の予告 | これから何が分かるかを先に言う | 首の後ろを温める順番を、3ステップでまとめました。 |
| H10 | 院の舞台裏 | 初回の流れ・考え方を見せて安心してもらう | 初回のカウンセリングで、最初にお聞きすることがあります。 |

## 使い分けの目安
- Threads：H1・H2・H7（会話になりやすい）
- Instagram：H3・H4・H9（保存されやすい）
- Googleマップ：H5・H6・H8（地域名と来院のきっかけを冒頭に）
- HPB・アメブロ：H5・H8・H10（タイトルに地域名）
- 同じ媒体で同じ型を3回続けない
